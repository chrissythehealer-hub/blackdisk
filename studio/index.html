  1. Download the notebook below.
  2. On kaggle.com/code: New Notebook → File → Import Notebook.
  3. Session options: Accelerator GPU T4, Internet on.
  4. Run All. Download first_video.mp4 from Output.
  5. Stop the session to save your free GPU hours.

Reference run: 832×480, 49 frames, 20 steps took 204 s on a Kaggle T4, after a one-time ~17 GB model download. Larger settings take longer.
