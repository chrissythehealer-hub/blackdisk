CREATE

Make your own
clip.

Describe the shot. We build a notebook with your settings; you run it free on Kaggle and download the MP4 about 10 minutes later.

  1. Download your notebook.
  2. Kaggle → Create → New Notebook → File → Import Notebook.
  3. Settings: Accelerator GPU T4 x2, Internet On (needs a verified phone number).
  4. Save Version → Save & Run All. Then open the version’s Output for first_video.mp4.
Start from

For image → video, add your photo in Kaggle (Input → Upload → New Dataset) before running. The first image found is used as the opening frame.

Advanced

Larger sizes and longer clips take much longer on a free T4. Start with a draft, then scale up. Kaggle gives about 30 free GPU hours a week.
